# devops-docs

Учебный репозиторий практической работы № 9 по Pylint, MkDocs, GitHub Actions и GitHub Pages.

- Исходники документации находятся в `docs/`.
- Конфигурация MkDocs находится в `mkdocs.yml`.
- Модуль для статического анализа находится в `src/status.py`.

Каталог `site/` создаётся при сборке документации и исключён из Git.
